# ПОТОК — приложение

Рабочее место аналитика цифрового двойника отгрузки. Инструкции запуска, статус и доступы — в [основном README](../README.md).

## Команды

```text
pnpm local          # сборка, миграции и локальный сервер на 5173
pnpm local:prepare  # сборка и миграции, без сервера
pnpm db:local       # только локальные миграции
pnpm test
pnpm typecheck
```

Требуются Node.js 24+ и pnpm 11.25.0. Установка: `pnpm install --frozen-lockfile`. В режиме разработки: `node scripts/local.mjs --dev`. После изменения кода для демонстрации пересоберите приложение.

## Код

- `lib/engine/` — чистое дискретно-событийное ядро, проверка входа, статистика, временная проекция, воспроизведение сохранённого прогона.
- `lib/compute.worker.ts` — расчёты с прогрессом, вне основного потока интерфейса.
- `lib/server/` — сессии, роли, API, атомарная запись и проверка хеша данных.
- `components/potok-app.tsx` — шесть экранов рабочего места.
- `components/terminal-scene.tsx` — Three.js, состояния из тех же результатов, доступные точки интереса при отсутствии WebGL.
- `db/`, `drizzle/` — схема и миграции SQLite/D1.
- `tests/` — аналитические задачи, инварианты, SQL/API и воспроизведение.

## Хранение и сборка

Локальное хранилище: `.wrangler/state`. Оно используется и dev-сервером, и собранным приложением. Перезапуск не очищает данные. `scripts/local-db.mjs` применяет только недостающие миграции Wrangler; уже существующая начальная схема принимается после точного сравнения. Удалённых операций этот скрипт не выполняет.

`dist/` — результат сборки. `outputs/experiments/` — воспроизводимые расчётные артефакты; `outputs/benchmarks/` — измерения этого компьютера. `.sites-runtime/` и `.vinext/` — служебное состояние инструментов. Пароли пользователей хешированы с солью; токены сессий не сохраняются в открытом виде.

Основа: React/TypeScript, Vinext/Vite, Cloudflare Worker + D1, Three.js и Recharts. Сохраняется интеграция Sites в Vite для будущей публикации; сейчас приложение локальное и не опубликовано. Демо-авторизация ПОТОК самостоятельная и не требует ChatGPT sign-in.
