# Журнал архитектурных и продуктовых решений

## ADR-001. Предметная область

**Принято.** Условный терминал автомобильной отгрузки нефтепродуктов в контексте «Газпром нефти». На афише — «Газпром нефть» и «Газпромнефть — Цифровые решения». Пользователь разрешил самостоятельный выбор в группе Газпрома. Источники подтверждают совпадение процесса и заказчика. Потребность именно в нашем инструменте — гипотеза для интервью, не доказанный недостаток действующей системы.

## ADR-002. Способ моделирования

**Принято.** Дискретно-событийная модель, отделённая от UI и хранения. Состояние меняется на событиях; нет шага в одну минуту, который округляет длительности и создаёт скрытые ошибки. Чистая функция с типизированными входами, seed и результатом. Прямые аналитические тесты и инварианты обязательны.

## ADR-003. Технологии

**Принято для веб-части.** TypeScript, React/Vinext, Three.js. Расчётное ядро TypeScript без внешних библиотек, запускается в Node и отдельном browser worker. Это позволяет локальную демонстрацию, быстрые расчёты без интернета и повторное использование одного кода в тестах. Базовый starter поддерживает серверные маршруты и SQLite-совместимую D1; сетевой хостинг не должен быть обязательным для защиты.

Node 24.22.1 и TypeScript 5.9.3 проверены локально. Менеджер пакетов — pnpm 11.25.0, потому что в среде нет npm CLI. Версии зафиксированы lockfile. Разрешены только ожидаемые build scripts esbuild/sharp/workerd. Посторонние starter-компоненты не считаются реализованными функциями продукта.

## ADR-004. Эксперименты

**Принято.** Парные случайные множители по ID операции, фиксированный спрос, отдельные seeds поиска и проверки. Показывать ограничения модели и условные расходы. Не использовать термин «ИИ» для перебора сетки. Не утверждать глобальный оптимум.

## ADR-005. Эффектная демонстрация

**Принято.** 3D — наблюдаемое представление состояния той же модели. Идентификаторы постов и резервуаров совпадают с данными. Не создавать независимую декоративную анимацию, выдаваемую за работающий двойник. Детализация условная, геометрия не копирует действующий объект.

## ADR-006. GitHub и публикация

**Принято.** Пользователь отложил GitHub до возвращения. Не создавать и не менять его удалённые репозитории. Исходники и журнал сохраняются локально. Закрытый Sites-проект зарегистрирован до этого уточнения, остаётся неопубликованным до готовности веб-части. Нельзя публиковать пустой starter или объявлять URL работающим до успешного развёртывания.

## ADR-007. Наращивание продукта

**Принято.** Не пытаться закончить работу упрощённой однопроходной генерацией. Ворота качества определены в PROJECT_PLAN.md. Активная цель продолжает работу между проходами. При ограничениях сохранять обязательный проектный комплект и корректность модели; сокращать второстепенную декоративную детализацию.
